# results/ Directory

## Purpose

All final troubleshooting reports generated by NetSage AI are saved here.

## File naming convention

```
case_<CASE_ID>_<YYYYMMDD>_<HHMMSS>_report.txt
```

Example:
```
case_C002_20260829_140530_report.txt
```

## Contents of each report

Each `.txt` file includes:
1. **Case header** — timestamp, case ID, human review decision
2. **Case input** — symptoms, topology, and raw show command evidence
3. **Comparison summary** — agreement ratio between rule checker and AI
4. **Final findings** — accepted/edited by the human reviewer (or rejected)
5. **Reviewer notes** — any comments the reviewer added
6. **Next steps** — instructions for applying the fix in Packet Tracer + verifying

## Using the report

1. Open the latest report file for your case
2. Read the FINAL FINDINGS section (this has been approved/edited by a human)
3. Apply each suggested fix in Cisco Packet Tracer
4. Verify the fix: ping between previously-failing devices, confirm symptoms resolved
5. If the fix didn't work, re-run NetSage AI with more evidence or start a fresh diagnosis
